# Лабораторная работа № 1

Основной файл — **[Lab1.ipynb](Lab1.ipynb)**. Ноутбук выполнен: внутри сохранены
таблицы, графики, проверки и прогнозы. Все определения включены в ячейки,
поэтому для самостоятельного запуска рядом нужны только исходные CSV
и установленные зависимости. Регуляризация на дополнительные баллы не реализуется.

для неполных входов заполнение медианами предусмотрено, но качество
на них отдельно не оценивалось. CSV с исходными данными не изменены.

## Запуск

В этой папке уже подготовлено окружение `.venv`. В VS Code выберите его
Python как ядро ноутбука и выполните ячейки сверху вниз.

Для автоматического выполнения из PowerShell в папке `lab-1`:

```powershell
.\.venv\Scripts\python.exe run_lab.py
```

На другом компьютере сначала создайте окружение с Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_lab.py
```

`run_lab.py` заново собирает и выполняет ноутбук, обновляя `submission.csv`
и содержимое `results`. Собственные изменения в сгенерированном ноутбуке
при этом заменяются; для сохранения таких правок редактируйте исходники
или запускайте ячейки непосредственно в редакторе.

## Обязательные задания

- EDA: распределение цели, зависимости признаков, корреляции, выводы.
- Самописные z-score и min-max, включая постоянные столбцы.
- `LinearRegression.fit/predict`: аналитическая формула через SVD,
  полный градиентный спуск, стохастический спуск по одному наблюдению.
- Сравнение с `sklearn.LinearRegression` и `SGDRegressor(penalty=None)`.
- Самописные MSE, MAE, R², MAPE с проверками против sklearn.
- Самописные 5-fold разбиения с переобучением всей подготовки внутри fold.
- Самописная LOO с полным пересчётом подготовки на подвыборке 200 строк;
  дополнительно точная PRESS-формула на полной фиксированной матрице.
  Эти две оценки явно разделены в ноутбуке.

Улучшенная модель использует 282 признака: исходные числовые поля, one-hot,
логарифмы денежных величин, полиномиальный базис степеней 2–4 по шести
переменным и взаимодействия с бинарными показателями. Она линейна по весам;
другие обучаемые модели не используются. Все статистики подготовки
оцениваются по обучающей части разбиения.

## Файлы

- `linear_regression.py` — исходники алгоритмов, встроенные в ноутбук.
- `data_preparation.py` — очистка и подготовка признаков.
- `build_notebook.py` — сборка самостоятельного ноутбука из исходников.
- `run_lab.py` — сборка и выполнение текущим интерпретатором Python.
- `verify_algorithms.py` — численные проверки против sklearn, включая
  вырожденные матрицы, нулевые цели и воспроизводимость SGD.
- `results/` — графики, метрики, коэффициенты, итоговый `summary.json`.

Проверки алгоритмов запускаются отдельно:

```powershell
.\.venv\Scripts\python.exe verify_algorithms.py
```

Для сдачи остаются действия из PDF: отправка CSV на Kaggle, проверка
результата, загрузка выполненного ноутбука на GitHub и отметка в таблице
оценок со своим ником Kaggle.
